# Pastel Store - Local API

This repository contains the backend and Docker configuration for the Pastel Store Flutter application.

The backend uses PHP to handle API requests and MySQL to store product data.

## Components

- Docker
- Docker Compose
- PHP
- MySQL

## Features

- Local API server.
- MySQL database integration.
- REST API for product data.
- CRUD operations (Create, Read, Update, Delete).
- Supports Flutter application integration.

## How to Run

1. Make sure Docker Desktop is installed and running.
2. Clone this repository.
3. Open the project folder.
4. Run:

   `docker compose up -d`

5. Make sure all containers are running.
6. Connect your Flutter application to the local API server.
